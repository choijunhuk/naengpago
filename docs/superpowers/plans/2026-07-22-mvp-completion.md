# 냉파고 MVP 완성 계획

> 상태: 실행 중. 사용자가 단계별 승인 대기를 해제했으므로 안전한 로컬 작업은 자동 진행한다.

## 완료 기준

- mock 모드에서 온보딩/로그인부터 재고 등록, 사진 분석 검토, 레시피 추천, 조리 차감, 장보기 이동까지 끊김 없이 동작한다.
- 동일한 화면 계약이 Supabase 저장소로 교체 가능하도록 도메인 로직과 데이터 어댑터를 분리한다.
- Expo Router 화면, 디자인 토큰, 다크 모드, 정상/빈/로딩/오류 상태를 공통 컴포넌트로 제공한다.
- 순수 도메인 테스트, TypeScript, lint, seed 검증을 통과한다. Expo 번들 검증은 의존성 설치가 가능한 환경에서 수행한다.
- 실제 계정, Docker, API 키, 스토어 서명처럼 사용자 권한이 필요한 항목만 최종 체크리스트로 남긴다.

## 실행 묶음

1. 앱 상태 전이와 추천/차감/분석 확정 로직을 테스트로 고정한다.
2. Expo SDK 57, Expo Router, NativeWind, Query, Zustand 기반 앱 셸을 구성한다.
3. 20개 제품 화면과 핵심 사용자 흐름을 mock 저장소에 연결한다.
4. Supabase 클라이언트/Edge Function 경계와 오프라인 폴백을 연결한다.
5. 문서, CI, Maestro 흐름, 검증 결과와 사용자 후속 작업을 정리한다.
