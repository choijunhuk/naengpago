# 시드 데이터 표본 검수

검수일: 2026-07-22  
검수 범위: `scripts/seed-data.mjs`가 생성하는 master 362개, alias 1,532개, 레시피 91개

## 검수 기준

- 이름이 한국 사용자가 재고 검색에서 사용할 수 있는 식재료명인지 확인한다.
- 카테고리와 기본 수량 모델이 명백히 어긋나지 않는지 확인한다.
- 사진만으로 확정할 수 없는 정확한 중량은 시드 기본값으로 강요하지 않는다.
- alias의 `국산`, `신선`, `냉장`, `소포장` 변형은 상품 OCR에서 붙는 수식어를 제거하기 위한 검색 입력으로만 사용한다.
- 레시피 재료는 모두 `ingredient_master`에 연결되며, 조리법은 4단계에서 전문 검수할 수 있도록 `source`를 명시한다.

## 확인된 제한

- 일부 alias는 자연어 동의어가 아니라 상품명 앞의 유통 수식어를 포함한 정규화 보조값이다.
- 레시피의 조리 단계는 0단계 구조 검증용 템플릿이다. 4단계에서 80개 이상 레시피의 재료 양과 조리 문장을 별도 검수한다.
- master 기본 수량 타입은 등록 UI의 시작값일 뿐이며, 이미지 분석 후보와 사용자 항목에서 변경할 수 있다.
